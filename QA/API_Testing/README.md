# API Testing

## Descrizione

Questa sezione contiene esempi di test eseguiti su API REST utilizzando Python.

L'obiettivo è verificare:

* Status Code
* Struttura JSON
* Gestione degli errori
* Risposte dell'API

## Tecnologie Utilizzate

* Python
* Requests
* FastAPI
* Swagger

## Attività Svolte

* Test endpoint GET
* Test endpoint POST
* Validazione delle risposte
* Verifica dei dati restituiti

## Strumenti di Supporto

Durante lo sviluppo dei test API sono stati utilizzati strumenti di Intelligenza Artificiale come supporto per:

* Comprensione della documentazione API
* Revisione del codice Python
* Analisi degli errori
* Supporto durante il debugging

Strumenti utilizzati:

* ChatGPT
* Google Gemini
* GitHub Copilot

## Obiettivo Formativo

Questo progetto è stato realizzato per acquisire esperienza pratica nel testing delle API e nell'automazione dei controlli tramite Python.
