# QA Manual

## Descrizione

Questa sezione contiene esempi di attività di Quality Assurance eseguite durante lo sviluppo del mio portfolio personale.

L'obiettivo è dimostrare un approccio strutturato al testing manuale attraverso:

* Analisi dei requisiti
* Creazione di test case
* Esecuzione dei test
* Segnalazione dei bug

## Contenuto

* Test Cases Manuali
* Bug Report
* Evidenze di Test

## Strumenti Utilizzati

* Google Chrome
* Microsoft Edge
* GitHub
* Visual Studio Code

## Strumenti di Supporto

Durante lo sviluppo del progetto sono stati utilizzati strumenti di Intelligenza Artificiale come supporto per:

* Comprensione dei concetti di Quality Assurance
* Revisione della documentazione
* Generazione di idee per test case
* Analisi e risoluzione di problemi tecnici

Strumenti utilizzati:

* ChatGPT
* Google Gemini
* GitHub Copilot

## Obiettivo Formativo

Questo progetto è stato realizzato come esercizio pratico per sviluppare competenze di QA Manuale e comprendere il ciclo di vita del testing software.
