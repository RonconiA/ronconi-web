# Test Cases Manuali

## Informazioni Generali

Progetto:

Portfolio Web Personale

Ambiente di Test:

* Google Chrome
* Microsoft Edge
* Windows 11

Tipo di Test:

* Functional Testing
* UI Testing
* Navigation Testing

---

## TC-001 - Apertura Homepage

Obiettivo:

Verificare il corretto caricamento della homepage.

Passi:

1. Aprire il browser.
2. Accedere al portfolio.
3. Attendere il caricamento completo.

Risultato Atteso:

La homepage viene visualizzata correttamente.

Esito:

PASS

PASS

## TC-004 - Validazione Email

Obiettivo:

Verificare che il campo email accetti solo indirizzi validi.

Passi:

1. Aprire il modulo contatti.
2. Inserire una email non valida.
3. Fare clic su "Invia Messaggio".

Risultato Atteso:

Visualizzazione di un messaggio di errore.

Esito:

PASS
